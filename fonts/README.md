# Fonts

Work Sans Regular, 300 and 600 are bundled under the SIL Open Font License 1.1.
Copyright and the full license text are included in OFL.txt.
Project: https://github.com/weiweihuanghuang/Work-Sans

Work Sans is the default font, including gallery and album headings.
An optional HTTPS URL to a WOFF2 font can be configured for those headings.
The visitor's browser loads that font directly; no remote font is downloaded
or bundled by the app. The font host must permit cross-origin font loading.
Operators must have the necessary webfont rights for their chosen font.

Font files retain their own licenses, independently of the application's
AGPL-3.0-only license.
