# Security policy

## Reporting a vulnerability

Security reports are welcome. Please use [GitHub's private vulnerability reporting form](https://github.com/ikigaido-org/nextcloud-photo-gallery/security/advisories/new) to contact the maintainers privately. A GitHub account is required; no public email address is needed.

Please do not disclose vulnerability details in a public issue or pull request.

Include, where possible:

- The affected Photo Gallery and Nextcloud versions.
- Steps to reproduce the issue, or a minimal proof of concept.
- The potential impact and any relevant configuration.

Remove passwords, access tokens and personal data from examples and logs.

## Handling reports

We will review reports and use the private report to discuss findings and coordinate any fix and public disclosure. Please give us an opportunity to investigate before publishing vulnerability details. Let us know whether and how you would like to be credited.
